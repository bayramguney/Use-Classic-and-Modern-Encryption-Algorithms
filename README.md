# 🔐 Lab - Use Classic and Modern Encryption Algorithms

## 📖 Overview

This lab introduces the fundamentals of cryptography using **JCrypTool**, an open-source educational platform for learning encryption, decryption, and cryptographic concepts. It demonstrates how classical and modern encryption algorithms protect data confidentiality and highlights the differences between symmetric and asymmetric encryption methods.

## 🎯 Objectives

- Implement a **Classic Caesar Cipher** to encrypt and decrypt text.
- Use the **Advanced Encryption Standard (AES)** for modern symmetric encryption.
- Perform **RSA Public-Key Cryptography** for modern asymmetric encryption.
- Compare classical and modern cryptographic techniques.
- Understand the role of encryption in protecting sensitive information.

## 🛠️ Technologies & Tools

- **JCrypTool**
- **CSE-LABVM**
- Caesar Cipher
- AES (Advanced Encryption Standard)

- Symmetric & Asymmetric Cryptography

## 🔍 Lab Activities

### Part 1 – Classic Encryption (Caesar Cipher)
- Explored the JCrypTool interface.
- Encrypted plaintext using the Caesar cipher.
- Decrypted ciphertext using the same key.
- Experimented with different alphabets and shift values (including ROT13).

### Part 2 – Modern Symmetric Encryption (AES)
- Encrypted plaintext using **AES-128**.
- Configured a custom hexadecimal encryption key.
- Used ECB mode with PKCS#5 padding.
- Successfully decrypted the encrypted data.

### Part 3 – Modern Asymmetric Encryption (RSA)
- Generated a new RSA public/private key pair.
- Encrypted text using the public key.
- Decrypted ciphertext using the private key.
- Demonstrated the principles of public-key cryptography.

## 🔐 Key Concepts Learned

- Classical encryption provides basic message obfuscation but offers limited security.
- AES is a fast, secure symmetric encryption algorithm widely used to protect sensitive data.
- RSA enables secure communication through mathematically linked public and private keys.
- Modern cryptography relies on computational complexity to resist brute-force attacks.
- Encryption is a fundamental component of cybersecurity, protecting confidentiality, integrity, and secure communications.

## ✅ Outcome

Successfully completed encryption and decryption exercises using **Caesar Cipher**, **AES-128**, and **RSA** within JCrypTool, gaining practical experience with classical and modern cryptographic techniques used in today's cybersecurity environments.
